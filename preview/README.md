# Web visualization files

This directory contains web-optimized GeoJSON representations of selected layers from the Itupararanga zoning conflicts dataset.

These files are provided exclusively to facilitate direct map visualization through the GitHub interface.

## Available previews

- `APAitupararanga.geojson`
- `ConflPMPDM.geojson`
- `ClassAdequacaoUCT.geojson`

## Important

The GeoJSON files in this directory are visualization products and are not the primary analytical datasets.

They may contain simplified geometries to improve browser rendering performance.

For spatial analysis, quantitative measurements, cartographic production, or geoprocessing workflows, users should download the original Shapefile or GeoPackage datasets available in the numbered GitHub Releases.

The analytical datasets use SIRGAS 2000 / UTM zone 23S.

The GeoJSON previews are exported in geographic coordinates compatible with web visualization.

No analytical result should be recalculated from simplified preview geometries when the original dataset is available.
